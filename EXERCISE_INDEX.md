# Exercise index

Every exercise in the course, in book order: what kind it is, which model it needs, where its reference solution is, and its result in the latest verification run. Generated by `python dev/exercise_index.py` from the course data and `solutions/outputs/*/summary.json`; don't edit it by hand.

Practise each exercise yourself first with `./course.sh ex <id>`, then compare with `./course.sh solution <id>`. Full instructions: [README.md](README.md).

**Model needed:** *No model* runs offline. *Local or Claude* works with the free `qwen3.5:9b` or Claude. *Claude recommended* runs locally but works better on Claude. *Claude only* needs `PROVIDER=claude` and an API key.
